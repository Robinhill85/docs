A **forked subagent** inherits the parent's full conversation history and exact system prompt. In contrast, other [subagents](/oss/deepagents/subagents) receive only a task description and have no memory of the conversation that led up to the delegation.

Use forking when you delegate deep into an investigation to avoid subagents re-deriving context the parent already gathered. For example, hand an in-progress incident investigation to a subagent that drafts the postmortem.

## Configure a forked subagent

:::python
Set `mode: "fork"` on a @[`SubAgent`]. All @[`SubAgent`] fields are available:
`name`, `description`, `tools`, `model`, `middleware`, `interrupt_on`, `permissions`, and `response_format`.

`skills` is rejected if provided. `system_prompt` is allowed and is appended to the parent's inherited prompt as an addendum — but doing so breaks the prompt-cache reuse forking exists for, so leave it unset unless you have a specific need for fork-only instructions.

## How it works

A forked subagent's system message is not a static copy of the parent's prompt. The fork mirrors the parent's own prompt-producing middleware (skills injection, memory, custom middleware) and rebuilds an equivalent message itself, rather than replaying one the parent already produced.

That shared prefix lets the fork reuse the parent's prompt cache instead of starting cold. The fork's own tools still work normally, but expect cache misses where the fork's tool use diverges from the parent's.

The inherited history also includes a short preamble that marks it as a continuation, not a fresh request.

## Fork a `CompiledSubAgent`

A [`CompiledSubAgent`](/oss/deepagents/subagents#compiledsubagent) can also set `mode: "fork"`. This inherits the parent's message history the same way as a declarative fork (a @[`SubAgent`] with `mode: "fork"`), but keeps the compiled graph's own system prompt. A `CompiledSubAgent` is already fully built, so it cannot inherit a system message.

## When to use forking

To consider when to use forking, consider the following dimensions:

| Dimension | Isolated (default) | Forked |
|-----------|---------------------|--------|
| **Context** | Only the task description you pass in | The parent's full conversation history and system prompt |
| **Prompt caching** | Builds a new prompt from scratch | Reuses the parent's cached prompt prefix |
| **System prompt and skills** | You set them on the subagent | Skills not settable; system prompt appends to the parent's (breaks caching, so usually left unset) |
| **Calling other subagents** | Can use the `task` tool | Cannot use `task`; must finish the work itself |
| **Best for** | Focused work that needs little prior context | Continuing an investigation the parent has already started |
